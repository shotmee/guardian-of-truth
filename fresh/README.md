# Guardian of Truth — veritas

Детектор ошибок («галлюцинаций») LLM-агента: по контексту диалога и ходу агента возвращает метку 0/1.

Запуск (как на платформе):

```
pip install .
python scripts/predict.py --input <test.parquet|csv> --output <predictions>
```

Выход — parquet с колонками `id` (string) и `label` (int64). Стратегия задаётся в `src/veritas/config.json`.

## Устройство

| модуль | что делает |
|---|---|
| `transcript.py` | разбор транскрипта: реплики, вызовы инструментов, ответы среды, текущее время |
| `tool_schema.py` | разбор раздела `[AVAILABLE TOOLS]` в спецификации инструментов |
| `checks.py` | детерминированные проверки хода: недоступный инструмент, схема и enum, заглушки, discoverable-инструменты без разблокировки, повтор провалившегося вызова, правила политик доменов |
| `analysis.py` | разбор всех примеров входного файла и срабатывания проверок |
| `probes.py` | детерминированные решения без модели (`probe_hard`, `probe_hardtext`, `probe_text`) |
| `cli.py` | точка входа: зонд или ранжирование моделью |
| `ranking.py`, `engine.py`, `chat.py` | ранжирование ходов моделью через vLLM (только в архивах с весами) |
| `replay.py`, `audit.py`, `atoms.py` | стратегии ранжирования: модель играет агента / разбор с рассуждением / узкие вопросы к вызовам |

## Решения без модели (зонды)

- `probe_hard` — метка 1, если сработала хотя бы одна детерминированная проверка.
- `probe_hardtext` — метка 1, если сработала проверка или в ходе нет вызовов инструментов.

Такие архивы содержат только модули разбора и проверок; модель и vLLM не используются.
